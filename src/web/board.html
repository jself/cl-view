    Keyboard

    sLabel every button, card, tab and box on screen (in a dialog, the dialog's); type a label to click it. Esc gives up.
    Ctrl+KGo to a ticket (by key or title) or run a command. Tab on a ticket lists what you can do with it; Shift+Tab goes back.
    /Search the tickets shown; Enter goes to the first card, Esc leaves the box and keeps the search.
    h j k l, arrowsMove between cards (and Needs you, and the list's rows); Enter opens one. g / G go to the top and bottom of the column.
    q / nQuick ticket / New ticket.
    oThe operator chat. Hold v to talk to it (with voice on).
    EscLeave a text box (it keeps what you typed); again, close the dialog.
    ?This list.

    Single keys don't fire while you type in a box, and of these only s, Ctrl+K and ? work with a dialog open. Dialogs have their own: Ctrl+Enter creates the ticket in New ticket, and in a ticket's Test tab, p f n c walk the test plan.
